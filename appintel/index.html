Agent architecture & method

  1. Dataset: 100 applications with categories and starting URLs.
  2. Discovery: Composio focused official-documentation searches.
  3. Evidence: Raw responses are saved and reused; only actual URLs and crawled content are extracted.
  4. Extraction: Gemini produces structured Pydantic-validated JSON using evidence only.
  5. Verification: Field-level claims are checked against manual sources and refined.
  6. Analysis: CSV, JSON, charts and this HTML matrix are generated from the resulting dataset.
